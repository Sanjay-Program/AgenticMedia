Enterprise Tech Stack

Production-grade monorepo architecture built for scale, security, and autonomy.

🖥️ Frontend

  • Next.js 16 (App Router)
  • React 19 Server Components
  • Tailwind CSS 3
  • Socket.io real-time feeds

⚙️ Backend API

  • Express.js REST API
  • Swagger/OpenAPI docs
  • JWT + ABAC authorization
  • AES-256-GCM encryption

🗄️ Database

  • PostgreSQL (5 schema phases)
  • Double-entry ledger
  • Event sourcing (event_log)
  • Immutable audit trail

🏭 Workers

  • BullMQ job queues
  • Redis pub/sub
  • Background AI processing
  • Scheduled cron tasks
